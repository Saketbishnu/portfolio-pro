# **App Name**: Portfolio Pro

## Core Features:

- Hero Section: Display personal information, including name, role, a short bio, and a call-to-action button. This will act as a landing page for visitors.
- Project Showcase: Showcase projects with image cards, titles, descriptions, and links to GitHub repositories or live demos.
- Skills & Tools Display: A dedicated section to list technical skills and tools using icons or logos for visual appeal.

## Style Guidelines:

- Primary color: Use a clean white or light grey for the background to ensure readability.
- Secondary color: A darker grey or black for text to provide contrast.
- Accent: Teal (#008080) to highlight interactive elements and call-to-action buttons.
- Use a grid-based layout for consistent spacing and alignment.
- Subtle fade-in animations for sections as the user scrolls.
